# 📊 Mini Projeto – Análise do Mercado de Trabalho com Python

Este repositório contém um **mini‑projeto de Ciência de Dados (nível iniciante)** utilizando **Python, NumPy e Pandas**. O objetivo é praticar leitura de dados, análise exploratória, estatísticas básicas e manipulação de DataFrames a partir de um dataset grande e realista.

---

## 🎯 Objetivo do Projeto

Explorar e analisar um dataset fictício sobre o mercado de trabalho, respondendo perguntas como:

* Qual área profissional possui maior salário médio?
* O nível de escolaridade impacta o salário?
* Existe relação entre anos de experiência e remuneração?

---

## 🧠 Conceitos Trabalhados

* Leitura de arquivos CSV
* Inspeção e limpeza de dados
* Estatística descritiva
* Indexação booleana
* Operadores lógicos
* `groupby` e agregações
* Integração entre **NumPy** e **Pandas**

---

## 📦 Dataset

Arquivo: `dataset_trabalho.csv`

### Características

* 50.000 linhas
* Dados totalmente fictícios
* Distribuições inspiradas em cenários reais

### Colunas

| Coluna                     | Descrição                           |
| -------------------------- | ----------------------------------- |
| `id`                       | Identificador único                 |
| `idade`                    | Idade da pessoa                     |
| `salario`                  | Salário mensal (R$)                 |
| `anos_experiencia`         | Anos de experiência profissional    |
| `nivel_educacao`           | Fundamental, Médio, Superior ou Pós |
| `horas_trabalhadas_semana` | Carga horária semanal               |
| `area`                     | Área profissional                   |
